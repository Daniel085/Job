## About the role

The role sits in Anthropic's Platform Org, which covers APIs, self-serve developer experience, multi-cloud integrations, and agentic infrastructure. The org has three areas:

- Enterprise fabric: multi-cloud integrations at scale
- Frontier capabilities: developer experiences and model features
- Agentic platform: agentic infrastructure and products

## Responsibilities

- **Customer understanding:** Engage enterprise developers and technical leaders, run feedback sessions, and turn insights into product requirements.
- **Product strategy:** Define the enterprise API strategy, balancing security with developer experience, and build a roadmap covering authentication, rate limiting, and compliance.
- **Enterprise API development:** Work with engineering on enterprise-grade API features, security controls, SDKs, and industry-specific capabilities.
- **Cross-functional leadership:** Partner with sales, customer success, security, compliance, platform teams, and marketing.
