# Examples Directory

This directory contains Daniel O'Rorke's actual job search materials as reference examples for new users.

## What's Here

### Profile-example.md
Daniel's complete professional profile showing:
- How to structure the 15 required sections
- Examples of quantified achievements with metrics
- Technical skills organization
- Compensation expectations formatting
- Interview talking points structure

**Use this as a formatting guide** when creating your own Profile.md.

###resumes/
8 tailored HTML resumes demonstrating:
- 2-page print-optimized format with CSS page breaks
- How to customize professional summary for each company
- Highlighting relevant experience for specific job requirements
- ATS-friendly HTML structure

**Key files:**
- `resume-designed.html` - Base template structure
- `resume-anthropic.html`, `resume-pagerduty.html`, etc. - Company-specific tailored versions

### cover-letters/
7 tailored cover letters showing:
- Opening hooks connecting candidate background to company mission
- Specific experiences with metrics matching job requirements
- Why this company/role specifically
- Clear next steps

**Pattern:** 60% length of initial draft (concise but impactful)

### jobs/
- `Similar-Job-Postings.md` - Example of curated job opportunities with fit scores (75-95/100)
- Demonstrates fit analysis format (✅ strengths + ⚠️ gaps)
- Shows score-sorted organization (highest fit first)

## How to Use These Examples

1. **Setting up your Profile.md?** → Read `Profile-example.md` to see what a complete profile looks like
2. **Creating a tailored resume?** → Compare `resume-designed.html` vs. company-specific versions to see customization approach
3. **Writing a cover letter?** → Review any cover letter to see the 4-part structure (hook, experiences, why company, next step)
4. **Building your jobs list?** → See how fit analyses reference specific profile evidence

## Important Notes

- These are **real application materials** used by Daniel for his job search
- **Do not copy content directly** - these are examples of structure and formatting only
- Your Profile.md, resumes, and cover letters should reflect **your** unique background and achievements
- Fit scores in the jobs list were calculated using Daniel's Profile-example.md - yours will differ based on your background

## What Makes These Good Examples

**Profile-example.md:**
- Comprehensive (435 lines covering all aspects of professional background)
- Quantified achievements ("10x growth", "$3M revenue", "40% reduction")
- Honest gap assessment in "Areas for Development"
- Clear compensation expectations and job search priorities

**Resumes:**
- Exactly 2 pages when printed (not 1, not 3)
- Customized professional summaries highlighting relevant experience for each role
- Project descriptions tailored to job requirements
- Clean, ATS-parseable HTML structure

**Cover Letters:**
- Concise (27-29 lines, ~60% of typical cover letter length)
- Specific metrics and examples (not generic claims)
- Research-backed references to company mission/products
- Professional but personable tone

**Jobs List:**
- Fit scores based on clear algorithm from Profile.md evidence
- Honest gap assessment (⚠️) alongside strengths (✅)
- Active links verified at time of addition
- Sorted by fit score (best matches first)
